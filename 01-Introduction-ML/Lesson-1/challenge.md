# AI vs ML vs Deep Learning vs Data Science

## Artificial Intelligence (AI)

AI is the biggest field.
It makes machines perform tasks that normally
require human intelligence.

## Machine Learning (ML)

ML is a part of AI.
It allows computers to learn from data.

## Deep Learning

Deep Learning is a type of Machine Learning
that uses neural networks.

## Data Science

Data Science uses programming, statistics,
and machine learning to analyze data.
