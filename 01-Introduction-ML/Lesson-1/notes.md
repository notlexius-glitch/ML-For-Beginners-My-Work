
# Introduction to Machine Learning

## What is Machine Learning?

Machine Learning (ML) is a way to teach computers
to learn patterns from data and make predictions.

Instead of writing every rule manually, we give data
to a computer and it learns from examples.

## Examples of Machine Learning

- YouTube video recommendations
- Spam email detection
- Weather prediction
- Disease prediction
- Fraud detection

## Types of Machine Learning

### 1. Supervised Learning

The computer learns from labeled examples.

Example:
Predicting house prices using previous house data.

### 2. Unsupervised Learning

The computer finds hidden patterns in data.

Example:
Grouping customers with similar interests.

### 3. Reinforcement Learning

The computer learns by rewards and mistakes.

Example:
Game-playing AI.
