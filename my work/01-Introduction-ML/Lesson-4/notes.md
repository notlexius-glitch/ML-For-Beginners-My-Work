
# Techniques of Machine Learning - Notes

## Machine Learning Process

Steps to build an ML model:

1. **Ask a Question** - Define what we want to predict.
2. **Collect and Prepare Data** - Gather, clean, and organize data.
3. **Choose Training Method** - Select an algorithm.
4. **Train Model** - Use training data to find patterns.
5. **Evaluate Model** - Test performance using unseen data.
6. **Tune Parameters** - Improve model accuracy.
7. **Prediction** - Use the model on new data.

## Important Concepts

### Data

Data is required to train machine learning models. Good quality data improves predictions.

### Features (X)

Features are input variables used by the model to make predictions.

### Target (y)

Target is the value that the model tries to predict.

### Training Data

Used to teach the model and find patterns.

### Testing Data

Used to check how well the model performs on new data.

## Model Problems

### Overfitting

Model learns training data too closely and performs poorly on new data.

### Underfitting

Model does not learn enough patterns and gives poor predictions.

## Model Evaluation

After training, models are tested using metrics to check accuracy and performance.

## Conclusion

Machine learning involves collecting data, training models, testing performance, and making predictions. Good data and proper model selection are important for successful ML systems.
