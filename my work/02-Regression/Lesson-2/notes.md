
# Lesson 2: Prepare and Visualize Data for Regression

## Overview

In this lesson, we learned how to prepare raw data for machine learning and visualize it before building a regression model.

## Learning Goals

- Clean and prepare datasets using Pandas.
- Handle missing and unnecessary data.
- Create new features from existing data.
- Visualize data using Matplotlib and Seaborn.

## Dataset Used

The lesson uses the **US Pumpkins Dataset** from the USDA.

The dataset contains:

- Pumpkin package information
- Date
- Low price
- High price

## Data Preparation Steps

1. Load dataset using Pandas.
2. Select important columns.
3. Remove unnecessary data.
4. Calculate average pumpkin price.
5. Extract month from dates.
6. Normalize prices based on package size.

## Important Libraries

### Pandas

Used for:

- Loading data
- Cleaning data
- Creating DataFrames
- Data analysis

### Matplotlib

Used for:

- Creating basic graphs
- Scatter plots
- Bar charts

### Seaborn

Used for:

- Advanced statistical visualization
- Heatmaps
- Relationship analysis

## Data Visualization

Visualization helps data scientists:

- Understand patterns
- Find relationships between variables
- Detect problems in data
- Choose suitable ML models

## Types of Visualizations

**Scatter Plot**

- Shows relationships between two variables.
- Helps identify possible linear relationships.

**Bar Chart**

- Shows average values across categories.

**Heatmap**

- Shows correlation between numerical features.

## Key Learning

Before creating a machine learning model, it is important to understand and prepare the data. Good visualization helps identify patterns and improves model selection.
