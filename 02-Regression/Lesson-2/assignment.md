
# Exploring Visualizations

## Task

Create visualizations using the Pumpkin dataset with Matplotlib and Seaborn.

## Exploration 1: Matplotlib Visualization

I used Matplotlib to create a bar chart showing the average pumpkin price for each month.

Matplotlib provides detailed control over graphs and allows customization of labels, titles, and styles.

## Exploration 2: Seaborn Visualization

I used Seaborn to create a bar chart and scatter plot to understand relationships in the pumpkin dataset.

Seaborn works directly with Pandas DataFrames and creates statistical visualizations with less code.

## Comparison

Both libraries are useful for data visualization.

- Matplotlib is better when detailed customization is required.
- Seaborn is easier for quick statistical analysis and creating attractive charts.

For exploring machine learning datasets, Seaborn is easier to use, while Matplotlib gives more control over final visual designs.

## Conclusion

Visualization helps understand patterns, relationships, and trends in data before creating a regression model.
