
# Challenge: Exploring Different Variables in Diabetes Dataset

## Task

Change the feature variable in the dataset and observe how it affects the diabetes progression prediction.

## Solution

I changed the selected feature column from BMI to another variable in the diabetes dataset and plotted the relationship with disease progression.

## Observation

Different features show different relationships with diabetes progression. Some variables have a stronger influence on the prediction than others. This shows why selecting important features is an important step in machine learning.

## Conclusion

Feature selection helps improve model performance and helps us understand which factors contribute most to the prediction.
